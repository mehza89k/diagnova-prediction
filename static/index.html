Transparency

Methodology & Transparency Hub

DiagNova is designed as an educational screening-support platform. This page details how information is processed without claiming unverified clinical outcomes.

1. Symptom & Lab Rule Processing

Inputs are evaluated against a structured multi-condition rule architecture. Missing laboratory values are explicitly handled and are never imputed as zero or "normal".

2. Emergency Pre-Screen Layer

Before any condition scoring takes place, a deterministic rule-based safety layer checks for red-flag warning terms. When triggered, routine scoring is halted immediately in favor of emergency guidance.

3. Confidence & Match Levels

Condition confidence is calculated from matched key symptoms, supporting symptoms, and laboratory criteria with weighted scores. Match levels (Strong / Moderate / Possible) help contextualize results — they are not probabilities or diagnoses.

4. PubMed Research Integration

Links open directly on NCBI PubMed via search queries for each condition. Relevance does not imply diagnostic confirmation.

5. What This Tool Is Not

This is not a medical device and has not been clinically validated. It does not replace a physical exam, laboratory confirmation, imaging, or professional clinical judgment.

Trust

Privacy & Security

Privacy is a core product requirement for DiagNova's Prediction.

  • Optional account: Firebase can manage email/password sign-in. Screening can still be used without an account.
  • Local-only storage: Screening results are stored in your browser's localStorage — nothing is sent to a server.
  • No third-party tracking: Health inputs are never shared with analytics or advertising networks.
  • Full user control: Delete any record or clear all history from the Records page at any time.
  • External links: PubMed links open in a new tab on pubmed.ncbi.nlm.nih.gov.

Use this tool on a trusted personal device. If you clear your browser data, saved records will be removed.
